# End-to-end agent-task success under compression

10 agent tasks over bloated tool outputs (avg 27,694 chars). Each task is a *code-consumer* step: parse the compressed output as its content type, then count / sum / list / look up over the parsed records. **Success is decided by real parsing + arithmetic, no LLM judge** — a mid-object fragment that an LLM could read but `json.loads` cannot parse fails, which is what a real agent pipeline hits.
